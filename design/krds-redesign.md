# 모바일 웹 디자인: KRDS 기반 재설계

2026-11-11 기준. 첫 화면이 "AI가 만든 것처럼 보인다"는 피드백을 받고, 웹 대시보드와 같은 기준인 KRDS(대한민국 정부 디자인 시스템)로 모바일 웹을 다시 만들었다.

## 바탕: KRDS

- 디자인 값은 KRDS 공식 저장소 [KRDS-uiux/krds-uiux](https://github.com/KRDS-uiux/krds-uiux)의 `resources/css/token/krds_tokens.css`에서 가져와 [tokens.css](tokens.css)에 넣었다.
- KRDS는 `1rem = 10px` 기준이라 px로 바꿔 적었다. 예: 모바일 본문 `1.7rem` → `17px`.
- KRDS 코드·이미지·컴포넌트는 복사하지 않았다. 화면은 규칙만 참고해 직접 만들었다.
- 공식 배너("이 누리집은 대한민국 공식 전자정부 누리집입니다")와 운영기관 표시는 넣지 않았다. KRDS가 공식 서비스에만 쓰라고 정했기 때문이다. 대신 푸터에 "정부 공식 서비스가 아닙니다"를 적었다.
- KRDS에는 다크 모드 값이 없다(라이트와 고대비만 있음). 그래서 다크 모드를 없앴다.

| 항목 | 쓴 값 |
| --- | --- |
| 주 색 | primary-50 `#256ef4`, 글자용 primary-60 `#0b50d0` |
| 본문 글자 | gray-90 `#1e2124`, 보조 글자 gray-70 `#464c53` |
| 입력 칸 테두리 | gray-60 `#58616a` (배경 대비 3:1 이상) |
| 상태 색 | danger-50 `#de3412`, warning-30 `#ffb114`, success-50 `#228738` |
| 글자 크기 | 본문 17px, 보조 15px, 작은 글자 13px, 제목 24·19·17px |
| 모서리 | 버튼·입력 8px, 작은 버튼 6px, 태그 4px |
| 높이 | 주 버튼·입력 56px, 보조 48px, 작은 버튼 40px |
| 간격 | 구역 사이 40px, 제목과 본문 사이 12px, 좌우 여백 16px |

## "AI가 만든 것처럼" 보이던 요소와 바꾼 것

| 전 | 후 |
| --- | --- |
| 둥근 카드 + 옅은 그림자, 파스텔 배경 | 그림자 없이 선과 면으로 구분, 흰 바탕 |
| 반짝이 아이콘이 붙은 "AI 설명" 표시 | 판별 요약의 "설명 작성: AI 생성" 한 줄 |
| 맥박처럼 뛰는 방패 애니메이션 | 번호 붙은 단계 목록 |
| 검은 알약 모양 칩 | 테두리 있는 선택 단추, 밑줄형 탭 |
| "~해요" 말투 | "~합니다" 말투 |
| 그라데이션 하단 바 | 흰 바탕 + 위쪽 선 |

## 글꼴

웹은 Pretendard를 쓴다(KRDS 기본 글꼴은 Pretendard GOV).

## 웹 대시보드와 다른 점

- 대시보드는 Tailwind로 만들었고, 이 모바일 웹은 일반 CSS로 만들었다. 둘 다 같은 [tokens.css](tokens.css) 값을 쓰므로 색·글자·간격은 같다.

## 정할 것

- 푸터에 넣을 운영 주체와 문의처. 지금은 서비스명과 데이터 출처만 있다.
- 통계 화면 출처 줄에 넣을 이용 허락 조건(예: 공공누리 유형). 데이터별로 확인이 필요하다.
- 통계 응답(`payload`) 구조가 확정되면 탭별 전용 차트로 바꾼다. 지금은 모양을 보고 꺾은선·막대·지도·표를 고른다.
